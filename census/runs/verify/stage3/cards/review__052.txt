RULE (plain words):
World: a random network of 200 nodes (average 4 links each). Nodes have 4 types (random start). Rules, applied in order each step: (1) each node adopts its neighbours' majority type (every step); (2) a node linked to a different-type neighbour cuts that link and links to a random same-type node (with probability 0.03 per step).

First-pass text (excerpt): **Verdict: KNOWN, with medium confidence.** The closest match is Fu & Wang (2008). Their model differs from this one in some details, but I don't expect those details to change the qualitative outcome.

**1. Model family.** This is a coevolving or adaptive opinion model, in the voter-model lineage but with a majority-rule update. Nodes take one of G=4 discrete opinions on an Erdős–Rényi graph. Each node adopts its local majority, and a node with a discordant link cuts it and rewires to a random node of the same type. This is homophilic rewiring, also called "rewire-to-same" or "partner switching".

**2. The specific behaviour.** Two things happen together: consensus, and a giant component of about 90% with extra components. Both are documented.

- **Earliest and closest source: Fu & Wang, Phys. Rev. E 78, 016104 (2008).**
  - I could read only the abstract. It combines majority-preference, where individuals adopt the majority opinion among their neighbours, with minority-avoidance, where they break the link to a differing minority node and rewire to a same-opinion node. The rewire target is either a neighbour-of-neighbour or a random node.
  - The network self-organises into connected communities of like-minded individuals, so many opinions coexist. The abstract says diverse opinions disappear into uniform opinion at other parameter values.
  - This is the same two-rule structure and the same consensus-versus-fragmentation trade-off as this system.

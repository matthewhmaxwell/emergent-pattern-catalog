RULE (plain words):
World: a 64x64 lattice of cells (wrap-around edges, 8 neighbours each); plus 400 self-propelled agents moving in a wrap-around square (20x20 when agents are alone, 64x64 when they share the lattice or fields); plus continuous chemical field(s) diffusing on a 64x64 wrap-around grid. Cells have 2 types (random start). Agents have 3 types (random start). Agents move at speed 0.3 with heading noise 0.3 rad per step. 1 field(s) with diffusion [0.05]. Rules, applied in order each step: (1) a type-1 cell becomes type 0 if at least 4 neighbours are type 0 (every step); (2) type-0 cells release 1.0 of field 0 per step.

First-pass text (excerpt): **Verdict: KNOWN.** The cell rule is threshold bootstrap percolation, and the field behaviour is a trivial consequence of having sources and no sink.

**1. Model family**

- **Cell rule.** A type-1 cell becomes type 0 if at least 4 of its 8 Moore neighbours are type 0. Type 0 never reverts, so the rule is monotone and irreversible. This is threshold-r bootstrap percolation, with type 0 as "infected" and r = 4 on the Moore neighbourhood.
- **Field.** The field is a diffusing scalar with constant sources (type-0 cells) and no decay term.
- **Agents.** The agents don't feed back into the lattice or field in this program, so they don't affect the result. I did not check how the second program (SCHELL, SAND, EMIT) couples them.

**2. Behaviour and sources**

- **The CA behaviour.** A random 50% start cascades irreversibly toward an absorbing, almost entirely type-0 state. This is the standard bootstrap-percolation phenomenon.
  - Earliest source: Chalupa, Leath and Reich, "Bootstrap percolation on a Bethe lattice", J. Phys. C 12 (1979) L31. I did not read this paper. The search only showed it cited as the origin of the model, and Hartarsky's paper credits the 2-neighbour model to it. The 1988 Aizenman and Lebowitz paper, "Metastability effects in bootstrap percolation" (J. Phys. A 21, 3801), also appeared only in a reference list.
  - Readable sources:
    - Hartarsky's paper calls a threshold bootstrap percolation model a simple cellular automaton, useful for metastability, glass

**What the system actually is.** With 3 types and type 0 being empty, there are only two kinds of agent plus vacancies. The cycle runs empty → 1 → 2 → empty. So rule (1) is not a three-species rock-paper-scissors game. It is a random, slowed-down version of the standard cyclic cellular automaton with range 1, threshold 3, 3 colours and the 8-cell neighbourhood (the rule known as "313"). Each update a cell's color advances by 1 if there are at least Threshold cells of the next color nearby, and R1/T3/C3/NM is a named, catalogued rule. In practice, empty cells get filled by type 1, type 2 takes over type 1, and type 2 empties out when surrounded by vacancy. That is an excitable-medium cycle in the Greenberg–Hastings family. Rule (2) is ordinary Schelling relocation to a random empty cell.

RULE (plain words):
World: a 64x64 lattice of cells (wrap-around edges, 8 neighbours each). Cells have 3 types (random start). Rules, applied in order each step: (1) a cell of type t becomes type t+1 (cyclically) if at least 1 neighbours already are t+1 (every step); (2) an occupied cell (type 0 = empty) whose same-type share among occupied neighbours is below 0.5 moves to a random empty cell.

  g_n_domains, g_largest_domain, g_reversals

First-pass text (excerpt): **Verdict: KNOWN.** This is a three-state cyclic cellular automaton (Griffeath's cyclic CA: each cell can only be taken over by the next type in the cycle) that is losing its diversity. In effect it is a rock-paper-scissors system where the moving pieces speed up the loss. The "segregation with vacancies" label is mostly a side effect of how the test measures things, not real Schelling segregation (Schelling's model of agents moving away from unlike neighbours).

**Why the label misleads.** In rule (1), type 0 (empty) is part of the cycle: 0→1→2→0. So "empty" behaves like a third species, not a fixed background of vacancies. That makes the system rock-paper-scissors with empty space as one player, plus random long jumps (rule 2). A whole lattice of one type is a dead end: once every cell is type t, no neighbour is t+1, so nothing changes again. The class result also barely changes when the Schelling threshold goes from 0.3 to 0.6, or the cycle probability from 0.1 to 1.0. That points to the cycle rule driving the outcome, with the Schelling move only acting as mixing.

**How the fingerprint fits.**
- **Threshold 1, three states, 8 neighbours:** this is the most excitable setting. In Fisch–Gravner–Griffeath's results, at very low thresholds, the entire lattice eventually oscillates periodically; sometimes the oscillation takes the form of large spiral waves which grow to engulf the entire lattice.

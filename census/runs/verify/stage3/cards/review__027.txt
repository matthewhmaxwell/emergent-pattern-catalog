First-pass text (excerpt): **Verdict: KNOWN.** This is the standard two-group Schelling model with vacancies, plus random noise that limits how far segregation goes. The first pass called it KNOWN-VARIANT, and I think that's wrong for three reasons.

**1. The first pass got the type count wrong.** The rule says "3 types" but type 0 is empty. So this is the usual setup: two kinds of agents plus vacancies. The literature uses exactly this encoding: each site takes one of three values: ±1 for the two kinds of agents and 0 for vacancies, and agents can only move if the vacancy density is above zero. Dropping "3 types instead of 2" removes half of the first pass's case for a variant.

**2. The swap step is just noise, and Schelling with noise is well studied.** Swapping neighbours at random with probability 0.1, regardless of how satisfied they are, works like exchange dynamics at infinite temperature. In other words, it's random mixing.

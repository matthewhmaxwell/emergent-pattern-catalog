RULE (plain words):
World: a random network of 200 nodes (average 4 links each). Nodes have 3 types (random start). Rules, applied in order each step: (1) each node copies the type of a random neighbour (every step); (2) a node linked to a different-type neighbour cuts that link and links to a random same-type node (every step).

First-pass text (excerpt): **Verdict: KNOWN.** I'm treating it as KNOWN rather than a variant because the differences from the textbook model look like implementation details. They are not a different mechanism.

**1. Model family**
- This is the adaptive (co-evolving) voter model with rewire-to-same.
- Each node copies a random neighbour's type. A node that has a discordant link cuts it and reconnects to a random node of its own type.
- This version has 3 states instead of 2.
- The "SAME CLASS" variants add copy probabilities below 1 and a FLIP rule with a spontaneous-change probability. Those are the noisy adaptive voter model.
- The CYCLE variants have a cyclic-dominance, rock-paper-scissors-like update and are discussed separately in point 3.

**2. The behaviour and its sources**
- **Earliest clear source:** Holme & Newman (2006) introduced the model with G opinions. They found a continuous phase transition as the balance parameter is varied, from a regime where opinions are arbitrarily diverse to one where most individuals hold the same opinion. I read this through the arXiv and Semantic Scholar pages.
- **Closest source to the three-state behaviour I observed:** Böhme & Gross, "Fragmentation transitions in multistate voter models", Phys. Rev. E 85, 066117. It studies models with an arbitrary number of opinions and gives detailed analytical results for a three-opinion model, confirmed by agent-based simulations.
- **Review-level sources:**
  - Böhme & Gross (arXiv 1012.1213) give an analytical app
